# Contributing to IntellMeet

Thank you for your interest in contributing to IntellMeet! We welcome contributions from everyone.

## Code of Conduct

Please be respectful and professional in all interactions within this project.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create a GitHub Issue and include:
- A clear description of the issue.
- Steps to reproduce the bug.
- Expected vs actual behavior.
- Screenshots or error logs, if applicable.

### Suggesting Enhancements
We welcome feature requests! Open a GitHub Issue and explain:
- The goal of the enhancement.
- How it should work.
- The benefits to the project.

### Pull Requests
1. **Fork the Repository** and clone it locally.
2. **Create a Branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Write Code**: Ensure your code follows the existing style guidelines and is well-documented.
4. **Test Your Changes**: Verify that your code builds and runs correctly.
5. **Commit and Push**: Use descriptive commit messages.
6. **Submit a Pull Request**: Provide a detailed description of your changes and reference any related issues.
